# 🏫 남서울대학교 엘림생활관 외국인 유학생 AI 한국 생활 & 기숙사 도우미

> **과목명:** 생성형AI활용프로그래밍 (기말 팀프로젝트 — 사회문제를 해결하는 AI 에이전트)  
> **주제:** 한국어가 서툰 외국인 유학생의 하루(아침·낮·저녁) 기숙사 및 한국 초기 생활 적응을 돕는 로컬 LLM 에이전트

## 1. 프로젝트 개요 및 사용자 시나리오

### 👤 가상 사용자 (Persona)
- **대상:** 2026년 9월 학기 남서울대학교에 입학하여 **엘림생활관(기숙사)**에 처음 입사한 외국인 유학생
- **반복되는 어려움:** 한국어가 서툴고 한국 대학·기숙사 문화를 잘 몰라 기숙사 통금 및 식사 시간, 쓰레기 분리배출, 버스 교통카드 환승 태그, 기숙사 외박 신청 및 교수님·사감 선생님께 연락하는 예절에서 매일 어려움을 겪습니다.

### 🕒 하루 시나리오 (아침 · 낮 · 저녁) 및 에이전트 개입 순간
| 시간대 | 유학생의 상황 및 반복되는 문제 | 에이전트의 개입 및 실행 동작 |
| :--- | :--- | :--- |
| **🌅 아침** | 기숙사에서 일어나 아침 식사 시간, 통금 시간, 세탁실 이용 시간 및 반입 금지 물품이 헷갈림 | **`search_campus_guide` (RAG)** 를 호출하여 엘림생활관 안내 문서에서 정확한 운영 시간과 생활 규칙을 쉬운 한국어로 안내 |
| **☀️ 낮** | 한국 생활 초기 쓰레기 분리배출(음식물 vs 일반), 시내버스 환승(하차 태그), 학식 식판 반납 등 생활 규칙을 몰라 실수함 | **`search_korea_life_tips` (도구 호출)** + **RAG** 를 연결하여 한국 초기 생활 4대 필수 주의사항 체크리스트를 항목별로 안내 |
| **🌙 저녁** | 주말 외박 신청 마감 시간(`22:00`)과 벌점 규정을 확인하고, 사감 선생님·교수님께 정중한 한국어로 연락하고 싶음 | **`dorm_and_korean_helper` (도구 호출)** 를 실행해 외박 신청 체크리스트와 한국 대학 예절에 맞는 **존댓말 메시지 템플릿**을 생성 |

## 2. 사용한 수업 기술 (총 3가지 기술 연결 + 로컬 LLM)

본 프로젝트는 수업에서 배운 기술 중 **3가지 기술(RAG + 도구 호출 + LangGraph)**을 로컬 LLM과 연결하여 구현하였습니다.

1. **로컬 LLM (Ollama — `ChatOllama`)**
   - 로컬 PC 환경에서는 가벼운 `qwen2.5:3b` 모델을 기본으로 실행하며, 학교 GPU 서버 환경에서는 `exaone3.5:7.8b` 또는 `qwen2.5:7b` 모델로 즉시 전환할 수 있도록 구성했습니다 (`temperature=0.0` 설정으로 환각 방지).
2. **기술 1 — RAG (Retrieval-Augmented Generation)**
   - `data/campus_guide.txt`에 정리된 남서울대학교 엘림생활관 수칙 및 한국 생활 가이드를 `RecursiveCharacterTextSplitter`로 분할하고, 다국어 임베딩 모델(`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`)과 **FAISS** 벡터 스토어를 이용해 관련 문서를 검색합니다.
3. **기술 2 — 도구 호출 (Tool Calling / Function Calling)**
   - `@tool` 데코레이터로 구현된 3종의 도구를 LLM에 바인딩(`llm.bind_tools`)하여 사용자 질문에 따라 호출합니다:
     - `search_campus_guide`: 기숙사 규칙 및 교내 시설 RAG 검색 도구
     - `search_korea_life_tips`: 한국 초기 생활 주의사항(쓰레기 분리배출, 버스 하차 태그, 학식 셀프 반납·전자출결, 220V 콘센트·택배) 조회 도구
     - `dorm_and_korean_helper`: 기숙사 외박 신청 마감(`22:00`) 체크리스트 및 사감실·교수님 연락용 정중한 한국어 메시지 작성 도구
4. **기술 3 — LangGraph (`StateGraph` 상태 기반 조건부 분기)**
   - 실행 흐름: `START → router_node → (Conditional Edges) → clarification_node 또는 campus_agent_node → END`
   - 사용자가 *"한국에 처음 왔는데 주의할 점이 뭐야?"*처럼 주제를 특정하지 않고 모호하게 질문하면 **`clarification_node`**로 분기하여 임의로 추측하지 않고 어떤 주제(분리수거, 대중교통, 식당·수업, 전기·택배, 기숙사 규칙)를 원하는지 **사용자에게 먼저 되묻습니다(사람 확인 요청)**.

## 4. 새로운 컴퓨터(또는 학교 GPU 서버)에서 설치 및 실행하는 방법

처음 세팅하는 새로운 컴퓨터에서도 아래 **5단계**만 순서대로 따라 하면 바로 챗봇을 실행할 수 있습니다.

### 1단계: 프로젝트 파일 준비
새로운 컴퓨터에 프로젝트 폴더(`app.py`, `requirements.txt`, `README.md`, `data/campus_guide.txt`)를 복사하거나 GitHub 저장소를 클론(`git clone`)합니다.

### 2단계: Python 설치 확인
1. **Python 3.10 이상**이 설치되어 있는지 확인합니다. (미설치 시 https://www.python.org/downloads/ 에서 다운로드)
2. **Windows 설치 주의사항:** 설치 첫 화면 하단의 **`☑ Add python.exe to PATH`** 옵션을 반드시 체크한 뒤 설치합니다.
3. 터미널(`cmd` 또는 `PowerShell`)을 열고 버전을 확인합니다:
   ```bash
   python --version
   ```

### 3단계: Ollama 설치 및 로컬 LLM 모델 다운로드
1. https://ollama.com/download 에서 운영체제(Windows / macOS / Linux)에 맞는 **Ollama**를 설치합니다.
2. 터미널에서 아래 명령어를 실행하여 `qwen2.5:3b` 모델을 다운로드합니다:
   ```bash
   ollama pull qwen2.5:3b
   ```
   *(※ 학교 GPU 서버에서 실행할 경우 `ollama pull exaone3.5:7.8b` 또는 `ollama pull qwen2.5:7b`를 다운로드한 뒤, `app.py` 상단의 `MODEL_NAME` 변수를 해당 모델명으로 변경하면 더 높은 품질로 동작합니다.)*

### 4단계: 필수 파이썬 라이브러리 설치
터미널에서 프로젝트 폴더로 이동한 뒤 `requirements.txt` 패키지를 설치합니다:
```bash
cd "프로젝트_폴더_경로"
pip install -r requirements.txt
```
*(최초 실행 시 다국어 임베딩 모델 `paraphrase-multilingual-MiniLM-L12-v2`가 자동으로 다운로드됩니다.)*

### 5단계: Gradio 웹 에이전트 실행
```bash
python app.py
```
- 터미널에 `Running on local URL: http://127.0.0.1:7860` 메시지가 출력되면 웹 브라우저를 열고 **`http://127.0.0.1:7860`** 에 접속합니다.
- **학교 GPU 서버에서 외부 브라우저로 접속해 시연할 때:**  
  `app.py` 하단의 `demo.launch(...)` 부분을 아래와 같이 변경하여 실행합니다:
  ```python
  demo.launch(
      server_name="0.0.0.0",
      server_port=7860,
      share=True,
  )
  ```

## 5. 테스트 시나리오 (정상 입력 1종 · 하루 시나리오 3종 · 예외 입력 2종)

Gradio 웹 화면 하단에 마련된 **5개의 예시 버튼**을 클릭하면 각 기능과 호출된 도구를 즉시 검증할 수 있습니다.

1. **🌅 [아침 시나리오 - 기숙사 규칙]**
   - **입력:** *"엘림생활관 아침 식사(조식) 시간과 기숙사 통금 시간, 세탁실 이용 시간 및 반입 금지 물품을 알려주세요."*
   - **확인 동작:** `search_campus_guide` (RAG) 호출 → 조식(`07:30~09:00`), 통금(`01:00~05:00`), 세탁실(`06:00~23:00`), 전열기구 금지 안내.
2. **☀️ [낮 시나리오 - 한국 생활 주의사항 (정상 테스트)]**
   - **입력:** *"한국에 처음 온 유학생인데 쓰레기 분리배출할 때 주의할 점과 버스 교통카드(환승) 이용할 때 꼭 지켜야 할 점을 알려주세요."*
   - **확인 동작:** `search_campus_guide` + `search_korea_life_tips` 도구 호출 → 일반쓰레기(달걀 껍데기·뼈·씨앗)와 음식물쓰레기 구분법 및 시내버스 하차 태그 필수 안내.
3. **🌙 [저녁 시나리오 - 외박 신청 & 한국어 예절]**
   - **입력:** *"이번 주말에 엘림생활관 외박 신청을 하고 싶어요. 신청 마감 시간과 사감 선생님께 드릴 정중한 한국어 인사말을 알려주세요."*
   - **확인 동작:** `search_campus_guide` + `dorm_and_korean_helper` 도구 호출 → 당일 밤 `22:00` 마감 안내 및 존댓말 메시지 템플릿 제공.
4. **🧪 [예외 테스트 1 - 모호한 질문 되묻기]**
   - **입력:** *"한국에 처음 왔는데 주의할 점이 뭐야?"*
   - **확인 동작:** LangGraph가 **`clarification_node`**로 분기하여 임의로 추측하지 않고 5가지 주의사항 주제 중 어느 항목을 먼저 알려줄지 되묻기 수행.
5. **🧪 [예외 테스트 2 - 문서에 없는 내용 (환각 방지)]**
   - **입력:** *"남서울대학교 기숙사에서 강아지나 고양이를 키워도 되나요? 기숙사 옥상 수영장 이용 시간도 알려주세요."*
   - **확인 동작:** 문서에 없는 내용을 지어내지 않고 *"현재 학교 및 기숙사 안내 문서에서 확인할 수 없습니다"*라고 안내.

## 6. 보안 · 윤리 · 비용 고려사항

- **개인정보 미수집:** 실제 개인정보를 수집하거나 저장하지 않으며, 사용자가 실수로 전화번호나 외국인등록번호 패턴을 입력하면 정규식(`sanitize_personal_info`)으로 즉시 `[개인정보 마스킹됨]` 처리합니다.
- **민감 분야(의료·법률) 배제 및 오작동 방지:** 잘못된 정보로 인한 피해 위험이 큰 의료(약 처방·진단) 및 출입국 법률 기능은 배제하고 안전한 캠퍼스·기숙사 생활 정보 안내로 범위를 한정하였습니다. 또한 모든 답변 하단에 실제 외박 및 행정 신청은 공식 학생포털에서 진행해야 한다는 안내 문구(`SAFETY_NOTICE`)를 표시합니다.
- **비용 효율성:** 유료 외부 API를 사용하지 않고 로컬 Ollama LLM(`qwen2.5:3b` / `exaone3.5:7.8b`)과 오픈소스 임베딩·FAISS를 사용하여 API 호출 비용이 **0원**입니다.
